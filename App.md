# Anivesariantes do Mês

**Nivel:** 1 - Iniciante
O sistema deve enviar uma mensagem via whatsapp para um número fixo que serar "+55 86 9986-0339".

Sera enviado o conteudo do arquivo NascimentoColaboradores.odt que se encontrata na pasta "Aniversariantes do Mes/",

São as mensagens:
1 - vai ser enviado as informações do arquivo em formato texto com os aniversariantes do em negrito,

2 - vai ser enviado outra mensagem no fromato texto dos aniversariantes do mês.

3 - Essas mensagens deve ser geradas e enviadas todo dia primeiro às 09:00 de cada mês,

4 - se não tiver nenhum anivesariante no mês enviar a segunda mensagem "Não temos Anivesariantes este Mês!"

5 - Após o envio das mensagens deve ser gerado lembretes das datas para que seja enviado mensagens na data referente ao aniversario às 09:00.

6 - Este programa deve ser execultado neste computador com base no linux, depois de criado deve ser encorparado para ferificar e rodar todo dia primeiro de cada mês.
